|---------|--------|---------------------|-------------------|
| Fresher, no job | Status fresher, no experience rows, backend goal | Foundation + stack core gaps | Visible in optional / D60+ stretch |
| Job + generic skills only | Resume with 2 jobs, skills like "Cloud Computing" | Baseline proof topics (Express, REST, …) | Optional stretch |

| Student | Status student, no job | Same as early — full path + optional advanced | Visible |
